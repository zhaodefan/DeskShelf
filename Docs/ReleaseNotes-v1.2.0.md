# 桌面置物架 v1.2.0

> 中文名：**桌面置物架**　英文项目名：**DeskShelf**

## 下载

| 文件 | 说明 |
| --- | --- |
| **DeskShelf-1.2.0-setup.exe**（推荐） | 安装程序。**免管理员权限**，装到 `%LOCALAPPDATA%\Programs\DeskShelf`，支持应用内一键升级 |
| **DeskShelf-1.2.0-portable-win-x64.zip** | 便携版。解压即用，不写注册表 |

自包含单文件，**无需预先安装 .NET 运行时**。系统要求：Windows 10 1809+ / Windows 11（64 位）。

## 本版新增：应用内在线更新

**不需要再去 GitHub 手动下载了。** 设置窗口新增「更新」区：

1. 打开 **设置 → 更新**，点「检查更新」
2. 有新版本时出现「**下载并安装**」按钮，点它并确认
3. 程序自动下载安装包 → 后台静默安装 → **自动重新启动**，全程约 1 分钟

也可以右键任务栏托盘图标 → **检查更新…**，会直接打开设置并开始检查。

### 实现方式与取舍

- 版本信息来自 **GitHub Releases API**（`/releases/latest`），只读公开接口，无需自建更新服务器
- 下载的安装包会做**字节级完整性校验**（与接口报告的大小比对），且下载到 `.part` 临时文件、**完整下载后才改名** —— 中途断网不会留下一个"看起来完整"的坏包
- 升级用 `/SILENT /SUPPRESSMSGBOXES /NORESTART /NOCANCEL` 参数调用**官方安装包**，保留进度窗口让用户看得见在进行
- **便携版不做自动替换**：便携版正在运行的文件无法被自己覆盖，此时只下载并打开所在目录，由用户解压替换（界面会明确提示）
- 安装失败（非 0 退出码 / 超时）时**不会关闭程序**，而是把原因显示出来

### 关于 GitHub 接口限流（重要）

未登录的 GitHub 接口限制为 **每 IP 每小时 60 次**查询，公司网络 / NAT 环境下很容易被用尽。
因此：

- 撞上限流时会明确告诉你**配额何时重置**，而不是笼统报"网络错误"
- 设置 → 更新 里可填入 **GitHub 访问令牌**（可选），配额提升到 5000 次/小时；令牌只保存在本机 `settings.json`，除查询版本外不用于其它用途

> 只读的公开令牌即可（不需要任何勾选权限）。

## 本版修掉的打包问题

- **安装器版本号不再硬编码**：以前 `.iss` 里手写 `AppVersion`，与 `Directory.Build.props` 各写一份，实际发生过「构建 1.1.0 却产出 `DeskShelf-1.0.99-setup.exe`」的错位。现在由发布脚本传入，单一来源。
- 发布脚本 `Build-Release.ps1` 传版本号给 ISCC，避免安装包文件名与程序集版本不一致。

## 完整功能

- **置顶小面板**：默认在鼠标所在屏右下角，位置尺寸自动记忆，可拖动可缩放
- **三类 unit**：文本（行内编辑 / 复制）、图片（缩略图 / 看图程序打开）、文件夹（资源管理器打开）
- **新建文本**：标题栏下方的「+ 新建文本」按钮，新建空白 unit 并立刻可输入
- **拖拽落盘**：文件夹 / 图片 / 普通文件都能拖入；**拖普通文件会存它所在的目录**；`.lnk` 会解析真实目标
- **多选与撤销**：`Ctrl+点击` 多选、`Shift+点击` 区间；删除后 5 秒内可撤销
- **全局热键** `Alt+X`（可在设置里改，带占用检测）
- **托盘常驻**：双击切换面板；退出走托盘右键菜单
- **明暗主题**：跟随系统 / 浅色 / 深色，切换即时预览
- **数据安全**：原子写入 + 防抖保存；数据文件损坏时自动备份并以空面板启动

## 快捷键

| 按键 | 行为 |
| --- | --- |
| `Alt+X` | 全局：呼出 / 收起面板（可改） |
| `Ctrl+V` | 面板内：存入剪贴板内容 |
| `Ctrl+C` | 复制选中的 unit |
| `Ctrl+Z` | 撤销最近一次删除 |
| `Delete` | 移除选中的 unit |
| `Esc` | 编辑中→提交；否则收起面板（不退出程序） |

## 数据位置

```
%APPDATA%\DeskShelf\
├─ shelf.json     面板内容      ├─ settings.json  设置（含可选令牌）
├─ images\        图片原件与缩略图
├─ updates\       下载的安装包    ├─ logs\  运行日志      └─ backup\  损坏数据自动备份
```

> 从 v1.0.0（DeskTools）升级会自动迁移 `%APPDATA%\DeskTools`；卸载时默认保留用户数据。

## 已知限制

- **把资源管理器窗口（标题栏 / 地址栏）直接拖进面板保存该目录**：做不到。拖放是"拖源"主导的协议，标题栏属于非客户区，系统把它处理成"移动窗口"而非数据传输。请改从**列表里拖文件夹**，或**拖目录里的任意文件**（会存其所在目录）。
- 在线更新需要网络；无法访问 GitHub 时请到发布页手动下载。
- `Alt+X` 属菜单助记符空间，个别程序前台时可能被其菜单占用；可在设置里换成 `Ctrl+Shift+...`。
