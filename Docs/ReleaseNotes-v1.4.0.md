# 桌面置物架 v1.4.0

> **交互改造**：悬停按钮改为**右键菜单**；新增**退格键快速删除**。
> 中文名：**桌面置物架**　英文项目名：**DeskShelf**

## 下载

| 文件 | 说明 |
| --- | --- |
| **DeskShelf-1.4.0-setup.exe**（推荐） | 安装程序，免管理员权限，支持应用内一键升级 |
| **DeskShelf-1.4.0-portable-win-x64.zip** | 便携版，解压即用 |

> **已在用 v1.2.2 及以上**：设置 → 更新 → 检查更新 → 下载并安装，可自动升级到本版。

## 改动 1：右上角悬停按钮 → 右键菜单

卡片右上角**不再出现**复制/打开/删除那组小按钮。改为**右键任意 unit** 弹出操作列表：

| unit 类型 | 菜单项 |
| --- | --- |
| 文本 | 编辑 / 复制 / 移除 |
| 图片 | 打开 / 复制 / 在资源管理器中显示 / 移除 |
| 文件夹 | 打开 / 在资源管理器中显示 / 移除 |
| 文件 | 打开 / 复制 / 在资源管理器中显示 / 移除 |

菜单项由该 unit 的**能力声明**推导，不存在按类型写死的分支：

- 文件夹按需求不支持复制到剪贴板 → 不显示「复制」
- 文本的「打开」就是「编辑」→ 两者互斥，不会同时出现
- 没有打开动作的类型 → 不显示「打开」

**右键会先选中被点的卡片**（已在多选集合内的则保留整个选择），避免"右键 A 却删了之前选中的 B"。

## 改动 2：退格键快速删除

选中 unit 后按 **`Backspace`** 即可删除，与 `Delete` 等价。删除后 5 秒内仍可用 `Ctrl+Z` 撤销。

**安全边界**：正在行内编辑文本时，退格只删**字符**，绝不会删掉整张卡片。
（这层判断走的是"焦点是否在文本框内"，已实测：编辑框内连按 5 次退格，文本少了 5 个字符，卡片完好。）

## 顺带清理

移除悬停按钮后遗留的死代码一并删掉：`IconButton.Card` / `IconButton.Card.Danger` 两个样式（55 行）、
`UnitViewModel.SupportsInPlaceEdit`（已无引用）。

## 完整功能

| 类型 | 怎么进来 | 双击 | 右键菜单里的特殊项 |
| --- | --- | --- | --- |
| 文本 | `Ctrl+V` 粘贴 / 「+ 新建文本」 | 行内编辑 | 编辑 |
| 图片 | 粘贴或拖入图片文件 | 看图程序打开 | 在资源管理器中显示 |
| 文件夹 | 拖入文件夹 | 资源管理器打开 | 在资源管理器中显示 |
| 文件 | 拖入任意文件 | 默认程序打开 | 在资源管理器中显示 |

其他：置顶小面板（位置尺寸记忆、可拖动缩放）、多选与 5 秒撤销、全局热键 `Alt+X`、
托盘常驻、明暗主题、应用内在线更新、原子写入 + 防抖保存 + 损坏自动备份、per-user 免管理员安装。

## 快捷键

| 按键 | 行为 |
| --- | --- |
| `Alt+X` | 全局：呼出 / 收起面板（可改） |
| `Ctrl+V` | 存入剪贴板内容 |
| `Ctrl+C` | 复制选中的 unit |
| `Ctrl+Z` | 撤销最近一次删除 |
| `Delete` / `Backspace` | 移除选中的 unit（编辑文本时退格是删字符） |
| `Esc` | 编辑中→提交；否则收起面板（不退出程序） |
| 右键 unit | 弹出操作列表 |

## 数据位置

```
%APPDATA%\DeskShelf\
├─ shelf.json     面板内容      ├─ settings.json  设置
├─ images\        图片原件与缩略图
├─ updates\       升级用的安装包与脚本
├─ logs\          运行日志      └─ backup\  损坏数据自动备份
```

## 已知限制

- **把资源管理器窗口（标题栏 / 地址栏）直接拖进面板保存该目录**：做不到，原因见
  `Docs/Development-Plan.md` §13。请从列表里拖文件夹或文件。
- 在线更新需要能访问 GitHub；无法访问时请到发布页手动下载。
- `Alt+X` 属菜单助记符空间，个别程序前台时可能被其菜单占用；可在设置里换成 `Ctrl+Shift+...`。
