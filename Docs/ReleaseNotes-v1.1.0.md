# 桌面置物架 v1.1.0

> 中文名：**桌面置物架**　英文项目名：**DeskShelf**（原 DeskTools，本版更名）

## 下载

| 文件 | 说明 |
| --- | --- |
| **DeskShelf-1.1.0-setup.exe**（推荐） | 安装程序。**免管理员权限**，装到 `%LOCALAPPDATA%\Programs\DeskShelf`，自动创建开始菜单 / 桌面快捷方式，可选开机自启 |
| **DeskShelf-1.1.0-portable-win-x64.zip** | 便携版。解压即用，不写注册表 |

自包含单文件，**无需预先安装 .NET 运行时**。系统要求：Windows 10 1809+ / Windows 11（64 位）。

> **安装范围说明（与 v1.0.0 不同）**：本版**只提供 per-user 安装**，不再询问「为所有用户安装」。
> 原因是 v1.0.0 允许提权安装后会把程序放进 `Program Files`、快捷方式放进 `ProgramData`，
> 卸载项分散在机器级位置，一旦注册表项被清理就会留下**删不掉的孤儿目录**。
> 现在安装位置固定为 `%LOCALAPPDATA%\Programs\DeskShelf`，与「自启写 HKCU、数据写 %APPDATA%」保持一致，全程不弹 UAC。

## 本版改动

### 1. 项目更名：DeskTools → DeskShelf

- 中文正式名：**桌面置物架**；英文项目名：**DeskShelf**
- 界面标题、托盘提示、菜单、消息框文案全部更新为中文名
- 可执行文件、安装包、GitHub 仓库、命名空间同步更名
- **数据自动迁移**：首次启动时把 `%APPDATA%\DeskTools` 整体迁移到 `%APPDATA%\DeskShelf`
  （优先整体移动；跨卷或被占用时改为复制后删除；迁移失败不影响启动），**旧数据不丢失**
- 安装包沿用同一 AppId，**可从 v1.0.0 覆盖升级**

### 2. 新增「+ 新建文本」按钮

标题栏下方新增操作条，点「+ 新建文本」即可：

1. 在列表末尾新建一个空白文本 unit
2. 自动滚动到该卡片并**立刻进入编辑态、光标已就绪**
3. 直接打字即可；点击别处（或按 `Esc`）完成编辑

再次点击会先提交上一张正在编辑的卡片，不会丢内容。

### 3. 标题栏按钮顺序调整

右侧按钮由「设置 → 最小化」调换为 **最小化在最后**（更符合 Windows 习惯）：

```
撤销 · 清空 │ 设置 ⚙ · 最小化 ─
```

### 4. 修掉的问题

- **卸载不再误删用户数据**：v1.0.0 的静默卸载会连 `%APPDATA%` 里的用户数据一起删除
  （静默模式下确认框自动应答，默认按钮未生效）。现在规则是：**静默卸载一律保留数据**，
  交互卸载默认按钮为「否」，需要清理请显式传 `/DELETEUSERDATA=1`。
- **编辑中的内容不再丢失**：收起面板（`Alt+X` / 最小化）、从托盘退出、程序退出前，都会先提交正在编辑的文本 —— 之前「输入后直接收起面板」会丢掉这段文字
- **补全无障碍名称**：所有图标按钮（撤销 / 清空 / 设置 / 最小化 / 关闭）此前没有可访问名称，屏幕阅读器读不出来；现已补 `AutomationProperties.Name`
- **安装器不再允许提权安装**（见上方「安装范围说明」），从根本上避免孤儿目录
- 空态提示更新为「点上方的「新建文本」，或按 Ctrl+V 粘贴、把文件夹 / 图片拖进来」

## 完整功能

- **置顶小面板**：默认在鼠标所在屏右下角，位置尺寸自动记忆，可拖动可缩放
- **三类 unit**：文本（行内编辑 / 复制）、图片（缩略图 / 看图程序打开）、文件夹（资源管理器打开，不参与复制）
- **拖拽落盘**：文件夹 / 图片 / 普通文件都能拖入；**拖普通文件会存它所在的目录**；`.lnk` 会解析真实目标
- **多选与撤销**：`Ctrl+点击` 多选、`Shift+点击` 区间；删除后 5 秒内可撤销
- **全局热键** `Alt+X`（可在设置里改，带占用检测）
- **托盘常驻**：双击切换面板；退出走托盘右键菜单
- **明暗主题**：跟随系统 / 浅色 / 深色，切换即时预览
- **设置界面**：热键、开机自启、缩略图开关、unit 上限、打开数据目录、清空面板

## 快捷键

| 按键 | 行为 |
| --- | --- |
| `Alt+X` | 全局：呼出 / 收起面板（可改） |
| `Ctrl+V` | 面板内：存入剪贴板内容 |
| `Ctrl+C` | 复制选中的 unit |
| `Ctrl+Z` | 撤销最近一次删除 |
| `Delete` | 移除选中的 unit |
| `Esc` | 编辑中→提交；否则收起面板（不退出程序） |

## 数据位置

```
%APPDATA%\DeskShelf\
├─ shelf.json     面板内容      ├─ settings.json  设置
├─ images\        图片原件与缩略图
├─ logs\          运行日志      └─ backup\        损坏数据自动备份
```

> 从 v1.0.0 升级会自动迁移 `%APPDATA%\DeskTools`；卸载时默认保留用户数据（会询问）。

## 已知限制

- **把资源管理器窗口（标题栏 / 地址栏）直接拖进面板保存该目录**：做不到。拖放是"拖源"主导的协议，标题栏属于非客户区，系统把它处理成"移动窗口"而非数据传输，应用侧无法介入。请改从**列表里拖文件夹**，或**拖目录里的任意文件**（会存其所在目录）。详细分析见仓库 `Docs/Development-Plan.md` §13。
- 开机自启写在 `HKCU\...\Run`，指向当前 exe 路径；移动便携版目录后需在设置里重新勾选一次。
- `Alt+X` 属菜单助记符空间，个别程序前台时可能被其菜单占用；可在设置里换成 `Ctrl+Shift+...`。
