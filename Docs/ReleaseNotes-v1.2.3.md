## 这个版本是干什么的

代码与 v1.2.2 **完全相同**，只是版本号从 `1.2.2` 变为 `1.2.3`。用途是提供一个可升级的目标，
用来验证 v1.2.2 修复后的**应用内在线更新**链路是否真的端到端可用。

如果你正在用 v1.2.2，可以这样试一次：

1. `Alt+X` 呼出面板 → 点标题栏右侧 **⚙ 设置**
2. 向下滚到 **「更新」** → 点 **「检查更新」**
3. 应显示 **「发现新版本 1.2.3（当前 1.2.2）。」**，并出现 **「下载并安装」**
4. 点 **「下载并安装」** → 确认
5. 程序会自动下载（约 64 MB，显示进度百分比）→ 短暂退出 → 静默安装 → **自动重新启动**
6. 重启后在设置里应看到 **「已是最新版本（1.2.3）」**

整个过程约 1 分钟。升级日志写在 `%TEMP%\DeskShelf-update-<时间戳>.log`。

## v1.2.2 修了什么问题

v1.2.0 / v1.2.1 的应用内更新会在下载完成后报「**安装程序返回退出码 1**」，原因是：

- 安装包设置了 `AppMutex`（用于安装/卸载时自动关闭运行中的程序）
- 但更新是由程序自己启动安装包，此时程序必然还在运行
- 安装包因此弹窗要求先关闭程序，而该弹窗被 `/SUPPRESSMSGBOXES` 抑制后**自动选择了「取消」**

修复方式：改由**独立的 helper 进程**接管 —— 它先等主程序退出，再静默安装，最后重启新版本。

## 完整功能

- **置顶小面板**：默认在鼠标所在屏右下角，位置尺寸自动记忆，可拖动可缩放
- **三类 unit**：文本（行内编辑 / 复制）、图片（缩略图 / 看图程序打开）、文件夹（资源管理器打开）
- **新建文本**：标题栏下方「+ 新建文本」，新建空白 unit 并立刻可输入
- **拖拽落盘**：文件夹 / 图片 / 普通文件都能拖入；拖普通文件会存它所在的目录；`.lnk` 解析真实目标
- **多选与撤销**：`Ctrl+点击` 多选、`Shift+点击` 区间；删除后 5 秒内可撤销
- **全局热键** `Alt+X`（可改，带占用检测）
- **托盘常驻** + **明暗主题**（跟随系统 / 浅色 / 深色）
- **应用内在线更新**：设置 → 更新 → 检查更新 → 下载并安装
- **数据安全**：原子写入 + 防抖保存；数据文件损坏时自动备份并以空面板启动

## 数据位置

```
%APPDATA%\DeskShelf\
├─ shelf.json     面板内容      ├─ settings.json  设置
├─ images\        图片原件与缩略图
├─ updates\       下载的安装包与升级脚本
├─ logs\          运行日志      └─ backup\  损坏数据自动备份
```

## 已知限制

- **把资源管理器窗口（标题栏 / 地址栏）直接拖进面板保存该目录**：做不到。拖放由"拖源"主导，
  标题栏属于非客户区，系统按"移动窗口"处理而非数据传输。请从列表里拖文件夹，或拖目录里的任意文件。
- 在线更新需要能访问 GitHub；无法访问时请到发布页手动下载。
- `Alt+X` 属菜单助记符空间，个别程序前台时可能被其菜单占用；可在设置里换成 `Ctrl+Shift+...`。
